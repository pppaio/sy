## 一、项目需求

### 1.1 项目背景

随着旅游行业的快速发展，景区游客数量持续增长，游客对景区导航、路线规划的需求日益迫切。传统的纸质地图已无法满足游客实时查询、智能规划的需求。本项目旨在开发一个景区路径规划系统，帮助游客快速获取导游线路、查询最短路径，同时为景区管理方提供景点与路径的维护功能。

### 1.2 功能需求

根据项目要求，系统需实现以下六项核心功能：

（1）**创建景区景点分布图**：输入景区景点数量、名称及景点间路径与距离，构建图结构。系统支持有向图和无向图两种模式，默认使用无向图存储景区景点关系。

（2）**展示景区景点分布图**：以邻接矩阵形式输出景区所有景点间的距离关系，无连通路径以 ∞（32767）表示，自身到自身为 0。

（3）**输出导游线路图**：基于深度优先遍历（DFS）生成从指定景点出发的导游线路，覆盖所有可达景点，并构建导游线路图，同时计算总游览距离。

（4）**判断导游路线中是否存在回路**：检测导游线路中是否存在重复访问的景点，即判断导游线路图中是否存在回路，若存在则输出回路路径。

（5）**查询两个景点间的最短路径和最短距离**：基于迪杰斯特拉（Dijkstra）算法，计算并输出任意两个景点间的最短路径（含途经景点）及最短距离。

（6）**可自行扩展功能**：包括景点信息查询、边权重查询、边存在性检测等辅助功能。

### 1.3 用户角色

本系统面向两类用户：

- **景区游客**：查询景点信息、获取导游线路、查询最短路径
- **景区管理方**：录入景点与路径信息、维护景区分布图

## 二、项目设计

### 2.1 实现思路

本项目采用策略模式与工厂模式的组合设计，通过抽象接口层实现图操作的解耦。具体实现思路如下：

（1）**策略模式**：定义 `GraphOps` 结构体作为虚函数表，封装图的所有操作接口。不同的图存储结构（邻接矩阵、邻接表）实现各自的策略函数集，通过同一接口对外提供服务。

（2）**工厂模式**：通过 `createAdjacencyMatrixGraph()` 函数创建图实例，返回抽象的 `IGraph*` 指针，调用方无需关心具体实现细节。

（3）**SOLID原则落地**：
- **单一职责原则（SRP）**：每个模块只负责一项功能，`graph_matrix` 负责数据存取，`console_utils` 负责输入输出，`main` 负责流程编排。
- **开闭原则（OCP）**：新增邻接表等存储方式时，无需修改 `main` 函数，只需实现新的策略函数集。
- **依赖倒置原则（DIP）**：`main` 函数只依赖抽象接口 `IGraph`，不直接依赖具体实现。

### 3.2 数据结构实现

#### 3.2.1 邻接矩阵初始化

邻接矩阵采用二维数组存储，对角线为0（自身到自身），其余位置初始化为无穷大（INF=99999）：

```c
static void initWeightMatrix(int weightMatrix[MAX_VERTEX_COUNT][MAX_VERTEX_COUNT])
{
    int rowIndex, colIndex;
    for (rowIndex = 0; rowIndex < MAX_VERTEX_COUNT; rowIndex++) {
        for (colIndex = 0; colIndex < MAX_VERTEX_COUNT; colIndex++) {
            weightMatrix[rowIndex][colIndex] = (rowIndex == colIndex) ? 0 : INFINITE_WEIGHT;
        }
    }
}
```

#### 3.2.2 顶点添加

顶点按顺序添加到顶点表中，返回新顶点的编号：

```c
static int matrixAddVertex(IGraph *self, const char *vertexName, const char *vertexDesc)
{
    MatrixGraphImpl *impl = getImpl(self);
    if (impl->vertexCount >= MAX_VERTEX_COUNT) {
        return -1;
    }
    int newVertexId = impl->vertexCount;
    impl->vertexTable[newVertexId].vertexId = newVertexId;
    safeStringCopy(impl->vertexTable[newVertexId].vertexName, vertexName, MAX_VERTEX_NAME_LENGTH);
    safeStringCopy(impl->vertexTable[newVertexId].vertexDesc, vertexDesc, MAX_VERTEX_DESC_LENGTH);
    impl->vertexCount++;
    return newVertexId;
}
```

#### 3.2.3 边添加

边添加时进行越界检查和负值校验，无向图自动添加对称边：

```c
static int matrixAddEdge(IGraph *self, int fromVertexId, int toVertexId, int edgeWeight)
{
    MatrixGraphImpl *impl = getImpl(self);
    if (!isValidVertexId(impl, fromVertexId) || !isValidVertexId(impl, toVertexId)) {
        return -1;
    }
    if (edgeWeight < 0) {
        return -1;
    }
    impl->weightMatrix[fromVertexId][toVertexId] = edgeWeight;
    if (!impl->isDirected) {
        impl->weightMatrix[toVertexId][fromVertexId] = edgeWeight;
    }
    return 0;
}
```

### 3.3 关键函数实现

#### 3.3.1 DFS导游线路生成

DFS采用递归实现，使用visited数组标记已访问顶点，path数组记录访问路径，totalDistance累计游览距离：

```c
static void dfsRecursive(const MatrixGraphImpl *impl, int currentVertexId, 
                         int visited[], int path[], int *pathIndex, int *totalDistance)
{
    int neighborIndex;
    visited[currentVertexId] = 1;
    path[*pathIndex] = currentVertexId;
    (*pathIndex)++;
    
    for (neighborIndex = 0; neighborIndex < impl->vertexCount; neighborIndex++) {
        if (currentVertexId != neighborIndex &&
            impl->weightMatrix[currentVertexId][neighborIndex] != INFINITE_WEIGHT &&
            !visited[neighborIndex]) {
            *totalDistance += impl->weightMatrix[currentVertexId][neighborIndex];
            dfsRecursive(impl, neighborIndex, visited, path, pathIndex, totalDistance);
        }
    }
}
```

#### 3.3.2 回路检测

回路检测使用DFS配合inStack数组，检测当前递归栈中是否存在已访问的顶点：

```c
static int cycleRecursive(const MatrixGraphImpl *impl, int currentVertexId,
                          int visited[], int inStack[], int path[], 
                          int *pathIndex, int *hasCycleFlag)
{
    visited[currentVertexId] = 1;
    inStack[currentVertexId] = 1;
    path[*pathIndex] = currentVertexId;
    (*pathIndex)++;
    
    for (neighborIndex = 0; neighborIndex < impl->vertexCount; neighborIndex++) {
        if (currentVertexId != neighborIndex &&
            impl->weightMatrix[currentVertexId][neighborIndex] != INFINITE_WEIGHT) {
            if (!visited[neighborIndex]) {
                if (cycleRecursive(impl, neighborIndex, visited, inStack, path, pathIndex, hasCycleFlag)) {
                    return 1;
                }
            } else if (inStack[neighborIndex]) {
                *hasCycleFlag = 1;
                return 1;
            }
        }
    }
    
    inStack[currentVertexId] = 0;
    (*pathIndex)--;
    return 0;
}
```

#### 3.3.3 Dijkstra最短路径

Dijkstra算法使用dist数组记录最短距离，visited数组标记已处理顶点，predecessor数组记录前驱顶点用于路径回溯：

```c
static int matrixDijkstraShortestPath(const IGraph *self, int startVertexId, 
                                      int endVertexId, int *path, int *pathLength, 
                                      int *shortestDistance)
{
    const MatrixGraphImpl *impl = getConstImpl(self);
    int dist[MAX_VERTEX_COUNT], visited[MAX_VERTEX_COUNT], predecessor[MAX_VERTEX_COUNT];
    int count = impl->vertexCount;
    
    for (int i = 0; i < count; i++) {
        dist[i] = INFINITE_WEIGHT;
        visited[i] = 0;
        predecessor[i] = -1;
    }
    dist[startVertexId] = 0;
    
    for (int i = 0; i < count; i++) {
        int minDist = INFINITE_WEIGHT, u = -1;
        for (int j = 0; j < count; j++) {
            if (!visited[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        }
        if (u == -1) break;
        visited[u] = 1;
        
        for (int k = 0; k < count; k++) {
            if (!visited[k] && impl->weightMatrix[u][k] != INFINITE_WEIGHT &&
                dist[u] + impl->weightMatrix[u][k] < dist[k]) {
                dist[k] = dist[u] + impl->weightMatrix[u][k];
                predecessor[k] = u;
            }
        }
    }
    
    if (dist[endVertexId] == INFINITE_WEIGHT) return -1;
    
    *shortestDistance = dist[endVertexId];
    // 路径回溯...
    return 0;
}
```

## 五、项目总结

本次项目开发严格遵循指定 Git 分支管理策略、Commit 提交规范、驼峰命名规则；代码采用多文件模块化拆分，遵循声明式编程与 C 语言开发最佳实践，在设计时参考 SOLID 设计原则，保证代码低耦合、高可读性与可扩展性。开发全程使用功能分支独立开发，开发前同步基准分支，功能完成后标准化提交代码，最终合并至公共 feature 分支与 master 主分支，完成双人协同开发。

### 5.1 技术收获

（1）**C工程化能力**：掌握了多文件开发模式，学会了如何合理拆分模块，理解了工程化目录结构的意义。通过CMake构建脚本实现自动化编译，提高了开发效率。

（2）**数据结构理解**：深入理解了图的两种存储结构（邻接矩阵和邻接表）及其适用场景。邻接矩阵适合稠密图，邻接表适合稀疏图。通过实现邻接矩阵，掌握了二维数组与结构体的组合运用。

（3）**算法实现能力**：成功实现了DFS深度优先遍历、回路检测和Dijkstra最短路径三种经典图算法，加深了对图遍历和路径规划算法的理解。

（4）**设计模式应用**：在C语言中成功应用了策略模式和工厂模式，实现了"伪多态"效果，使代码符合SOLID设计原则。

（5）**Git协作能力**：学会了分支管理、冲突解决、合并等Git基本操作，体验了完整的团队协作流程。

### 5.2 问题与改进

（1）**中文乱码问题**：Windows控制台默认使用GBK编码，而源代码使用UTF-8编码，导致中文显示乱码。通过在编译时添加`-fexec-charset=GBK`参数解决了该问题。

（2）**输入验证问题**：初始版本对非法输入处理不完善，通过封装`consoleReadInt()`函数并检测返回值，有效避免了死循环问题。

（3）**内存管理问题**：在工厂函数中完善了malloc失败时的资源释放逻辑，防止内存泄漏。

### 5.3 展望

（1）可以进一步优化Dijkstra算法，使用优先队列降低时间复杂度。

（2）可以添加更多图算法，如Floyd-Warshall算法、拓扑排序等。

（3）可以开发图形化界面，提升用户体验。

（4）可以增加文件持久化功能，支持景点和路径数据的保存与加载。
